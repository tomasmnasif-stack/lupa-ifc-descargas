# Lupa IFC

Visor de modelos IFC para Windows: abrir, buscar, medir, pesar y sacar listados a Excel de modelos de
Tekla Structures, Advance Steel y otros programas BIM. También abre .ifcZIP y STEP (.stp).

## Descargar

Entrá a **[la última versión](../../releases/latest)** y bajá:

- **Windows:** `Lupa-IFC-Setup-x.y.z.exe`. Se instala con doble clic, sin permisos de administrador.
- **Tablet Android:** `Lupa-IFC-x.y.z.apk`.

La primera vez Windows puede mostrar **"Windows protegió su PC"**, porque el instalador no está firmado:
tocá **Más información → Ejecutar de todas formas**.

## Actualizaciones

Una vez instalado, Lupa IFC avisa solo cuando hay una versión nueva (botón naranja arriba): se toca y se
actualiza.

Los modelos se leen en la PC y no se envían a ningún lado. Aquí solo están los instaladores.
